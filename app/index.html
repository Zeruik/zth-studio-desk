从灵感到海报，只需几步

  1. 选择模板，或在“调整尺寸”里设置画布。
  2. 双击文字修改文案，拖动角点缩放，顶部手柄旋转。

创作从一个元素开始

从左侧添加文字、正方形、圆形或图片。拖动角点缩放，拖动旋转手柄旋转；右侧属性可以精确设置坐标、尺寸、比例、描边和颜色。手机上点顶部“属性”打开面板。

复用一个稳定的品牌模板

导入 LOGO，用取色抠图去掉底色，调整到右上角并锁定。将产品图片设为“可替换图片槽”，保存成自己的模板。下一次选中图片槽，点“替换图片”，位置、尺寸和层级都保持原样。

文件如何跨设备使用

保存 .zthpmsj 后，通过微信文件、数据线或其他方式传到手机或电脑，再从“上传 → 导入工程”打开。工程内嵌图片和默认字体，包含所有页面和锁定状态。工程没有加密，请自行管理备份。

导入与导出

PNG/JPG/WebP 可作为照片；SVG 导入为可拆分矢量；PDF 按页导入为图像；PPTX 读取基础文字、图片和矩形，母版和特效需检查。可画先导出这些格式。PNG/JPG 用于发布，SVG 保留形状，PDF 是整页图像。

快捷键

Ctrl+Z 撤销；Ctrl+Y 重做；Ctrl+D 复制；Ctrl+S 保存；Delete 删除；方向键微调，Shift+方向键移动 10 px。Shift 点选多个元素后组合。

Start with one element

Add text, rectangles, circles or images. Drag the corner handles to scale and the rotation handle to rotate. Properties provides exact position, dimensions, aspect ratio, strokes and colors. On a phone, tap Properties in the top toolbar.

Reuse a consistent brand template

Import a logo, remove its background with color sampling, position it in the top-right corner and lock it. Mark your product image as a replaceable image slot, then save the template. Next time, select that slot and choose Replace image: its frame and layer order stay in place.

Move a design between devices

Save a .zthpmsj file and transfer it by cable, messaging or your usual file tool. Open it from Uploads → Import. It contains every page, embedded images, the default font and lock states. Files are unencrypted; manage your own backups.

Import and export

PNG/JPG/WebP import as images. SVG imports as an editable group. PDF pages import as images. PPTX imports basic text, pictures and rectangles; check masters and effects. Export these formats from Canva first. PNG/JPG are ready to share, SVG preserves shapes and PDF is flattened.

Keyboard shortcuts

Ctrl+Z undo; Ctrl+Y redo; Ctrl+D duplicate; Ctrl+S save; Delete remove; arrows nudge, Shift+arrows move 10 px. Shift-click multiple elements to group them.
